# Lane Buddy API

Every route lives under `/api` on the admin port, `http://127.0.0.1:8754` unless the banner says otherwise. Every request needs the admin token in `X-Lane-Token: <token>` or `Authorization: Bearer <token>`, and a `Host` of `127.0.0.1` or `localhost`. The token is in `admin.token` in the Lane data folder, and the console prints a dashboard link with it in the fragment: `http://127.0.0.1:8754/#token=…`. A page reads it from `location.hash` and keeps it in `sessionStorage`.

Errors are `{"ok": false, "error": "<word>"}` with 400, 401, 403, 404, or 409.

## Ranges

`range` is `today`, `2d`, `7d`, `30d`, or `all`. A named range starts at a local midnight: today, yesterday, six days ago, twenty-nine days ago. `tz` is minutes east of UTC (`-new Date().getTimezoneOffset()` in a browser); without it the PC's zone is used. Chart buckets follow the range: `today` 1 h, `2d` 2 h, `7d` 6 h, `30d` 1 day, `all` fitted. Every timeline bar carries `t`, the bar's start in Unix milliseconds.

`critical` is true for a program no rule may stop and protection never pauses or closes. `trust` says why, or what a program is: `own` (one of LaneBuddy's programs in the running engine's folder; `verified` when the file matches the SHA-256 the release built into the engine), `own_changed` (one of those that no longer matches: not protected, and a finding), `own_build` (a LaneBuddy program or test run inside a LaneBuddy source checkout: a normal program), `system` (the operating system's own, from its folders), `name_copy` (a system's or LaneBuddy's name anywhere else: a normal program, and a finding), or empty. `/api/programs` rows carry `critical`, `trust`, and `verified` too.

`LiveProcess` is `{pid, ppid, name, path, cpu_percent, cpu_seconds, memory_bytes, gpu_percent (Windows, Pro), started (seconds), runtime_seconds}`.

`Route` is `{family (4/6), dest, prefix, gateway ("" when on-link), iface (alias), index, metric (the route's own), if_metric (the interface's; route print shows the sum), origin (manual/wellknown/dhcp/ra/6to4), proto (local/static/dhcp/redirect/other), persistent, since (seconds, 0 when it was there before LaneBuddy watched)}`.

`RouteChange` is `{id, t (ms), kind, family, dest, prefix, gateway, iface, metric, old_gateway, old_iface, old_metric, origin, proto, severity (alert/note), why, offline, by}`. `why` for an alert is `default`, `half_default`, `moved`, `persistent`, `dhcp_public` (a public route from DHCP, as in TunnelVision), `redirect` (ICMP), `bypass` (a public route around LaneBuddy's tunnel), or `broad` (a public /8 or wider); for a note `metric`, `moved` (a host route), `lane` (LaneBuddy's own tunnel), `virtual` (Hyper-V, WSL, Docker), `muted`, or empty. `offline` marks what changed while LaneBuddy was not running; `by` is the route tool (route.exe, netsh.exe, a VPN client) that started in the five seconds before, when the program watch saw one. `Change` in a diff is `{kind, route, old, severity, why}`.

`reason` and the `reasons` names are list ids: `user` (your block), `country` (a blocked country), `app` (a block for one app), `light`, `pro`, `pro_plus`, `ultimate` (ads and tracking), `tif`, `malware` (threats), `nsfw`, `adult`, `gambling`, `social`, `piracy`, `shortener`, `doh`.

`via` is `local`, `tunnel`, `tls`, or `fetch`.

## Free, Pro, and game mode

`tier` and `game_mode` live in the store's meta table and apply at once, without a restart.

| | Free | Pro | Pro with game mode |
| --- | --- | --- | --- |
| DNS filter and counts | yes | yes | yes |
| DNS log (`/api/dns/log`, `queries` table, `event: query`) | yes | yes | no; answered and blocked are counted per minute instead, so Übersicht keeps counting |
| Process list (`/api/processes`, `programs.running`, `programs.busy` above 10 % CPU) | every 5 s, no GPU | every 2 s | no |
| Program watch (starts, stops, program rules, stopping programs) | no | yes | no |

A store without a saved `tier` starts as `pro` when it already holds queries, program events, or program rules (an install from before the Free tier), and as `free` otherwise. `guard.paused` is true while the program watch is off. The status port (`LANE-STATUS` on UDP 8753) reports `tier=free` or `tier=pro` and `game_mode=on` or `game_mode=off`.
